# PanelPop

Windowsのウィンドウから必要な1〜4領域を切り出し、スマートフォンのブラウザにライブ表示する、独立したMITライセンスのアルファ版です。閲覧専用で開始し、PC側で許可した場合だけタップを左クリックへ変換します。

**0.1.0a2 / Windows 10・11 / Python 3.10以上。** 署名済みEXEは含みません。macOS・Linuxでは明示的な合成デモを使用できます。[English README](README.en.md)

0.1.0a2は公開前レビュー後の修正版です。Linuxでの今回の検証と、0.1.0a1のmacOS検証記録を分けて [検証記録](docs/VALIDATION.md) に記載しています。

## 起動

このリポジトリのルートで実行します。Windowsの例:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install .
.venv\Scripts\python -m panelpop --open
```

初期状態は `127.0.0.1:8765` のみに待ち受けます。ターミナルに表示される **PC admin** URLを同じPCで開いてください。`--open` はその画面を標準ブラウザで開きます。

スマホを接続する場合は、PCのプライベートIPv4アドレスを確認して明示的にLAN待受を有効にします。IPは例をそのまま使わず、自分のPCのアドレスへ置き換えてください。

```powershell
.venv\Scripts\python -m panelpop --lan --advertise 192.168.1.20 --open
```

PCとスマホを同じ信頼できるWi-Fiへ接続します。Windowsファイアウォールでは必要な場合のみプライベートネットワークでTCP 8765を許可してください。VPN、Wi-Fiの端末間通信制限、別サブネットなどでは到達できないことがあります。

## 操作

1. PC設定画面で対象ウィンドウを選び、「プレビューを表示」を押します。設定画面と対象を並べ、重ならないようにします。
2. ライブプレビューをドラッグし、1〜4個の領域を選択して「領域を適用」を押します。領域はクライアント画面内の整数ピクセルです。
3. PC設定画面のQRまたは接続URLをスマホで開きます。閲覧専用でライブ画像が更新されます。
4. 必要な場合、PC設定画面で「スマホ操作を許可」を選択します。スマホの画像のタップがPCの左クリックになります。
5. PC画面の常時表示される「停止」で画像と入力を停止します。再開はPCで行い、再び閲覧専用になります。`Ctrl+C` でホストを終了できます。

ウィンドウの位置・サイズ・PID・表示状態の変更、最小化や遮蔽を検出すると停止が保持されます。元に戻しても自動再開しません。PCで確認し「PCで再開」を押すか対象と領域を選び直してください。対象を閉じて別のアプリへ変わった場合は選び直しが必要です。設定画面の「選択領域」は現在編集中の領域で、再読込時の0表示は適用済み領域の解除を意味しません。

## 合成デモ

Windows以外でも実行できます。PCの実画面を撮影せず、OSへの入力を送らず、合成画像だけを更新します。許可したタップは画像内の黄色いマーカーとして表示されます。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m panelpop --demo --open
```

スマホでデモを試す場合も `--lan --advertise 自分のPCのIP` を付けます。

## 制限と安全性

- LANのHTTPは暗号化されません。信頼できる私有ネットワークだけで使い、インターネットへ公開しないでください。URL/QRは起動ごとの秘密トークンを含みます。漏れた場合はホストを終了し再起動してください。
- 管理トークンと閲覧トークンは別です。PC管理APIはTCP接続元のループバックアドレスだけを許可し、スマホから停止・再開・操作許可を変更できません。プロキシ公開には対応しません。
- 表示フレームは2秒で期限切れになります。古い/不明なフレーム、領域外や無効な座標からの入力を拒否します。通信失敗時は画像を消し、成功表示を出しません。
- 安全確認後とOS入力の直前にも期限を検査します。カーソルの実位置が指定座標と違う、または取得できない場合はクリックせず停止し、操作許可を解除します。
- 実画面キャプチャは「見えているデスクトップのクライアント領域」です。対象より上のウィンドウの重なりを保守的に拒否します。透明ウィンドウやポップアップでも拒否される場合があります。保護された映像等は正常に撮影できないことがあります。
- DPI awarenessと複数モニターの負座標を扱いますが、検査とOS入力は原子的ではありません。検査直後の画面変更による誤操作を完全には防止できません。安全が重要な操作には使わないでください。
- 入力はマウスカーソルを移動し、左ボタンのdown/upを送ります。昇格したアプリへの入力はWindowsのUIPIで制限されます。失敗を検出すると停止します。スクロール、キーボード、長押しには対応しません。
- 対象は最大1600万画素、各辺8192以下、領域数4、保存フレーム8、HTTP処理16接続、JSON入力32KiBです。停止は入力・撮影と同じロックで直列化されるため、進行中のOS処理完了を待つ場合があります。

## 検証・開発

```sh
python -m pip install -e . build
python -m unittest discover -s tests -v
python -m panelpop --help
python -m build
```
