PanelPop PC設定

ウィンドウを選び、必要な領域を取り出します。

合成デモ — 実際のPC画面の撮影やOSへの入力は行いません。

接続しています…

1. 対象ウィンドウ

対象とこの設定画面は、重ならないように並べてください。対象は前面に表示し、最小化しないでください。

2. 領域を選ぶ

ライブプレビュー上をドラッグして、1〜4個の矩形を選びます。領域を適用すると閲覧専用に戻ります。

選択領域: 0 / 4

3. スマートフォンを接続

PCと同じ信頼できるネットワークで、スマホからQRコードを読み取ります。LANで使うには、起動時に次のオプションが必要です: --lan --advertise IP

LAN内の通信は暗号化されません。共用のネットワークやインターネットには公開しないでください。
